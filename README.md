# افزونه ابزار های بوستان

<span align="center">

[![](https://wakatime.com/badge/user/42515572-c36c-44b6-9997-0a755ff94018/project/340de59b-f15d-4a38-b938-53e7bdb98980.svg?style=flat-square)](https://wakatime.com/@a710almasi/projects/cfnmrynsqg) [![](https://img.shields.io/github/package-json/v/alialmasi/nustools-ext?style=flat-square&label=Latest%20Version)](https://github.com/AliAlmasi/nustools-ext/releases/latest) ![](https://img.shields.io/github/downloads/alialmasi/nustools-ext/total?style=flat-square&label=Downloads)

افزونه NUSTools یک ابزار کمکی برای دانشجویان [دانشگاه ملی مهارت (فنی و حرفه‌ای سابق)](https://fa.wikipedia.org/wiki/%D8%AF%D8%A7%D9%86%D8%B4%DA%AF%D8%A7%D9%87_%D9%85%D9%84%DB%8C_%D9%85%D9%87%D8%A7%D8%B1%D8%AA) است که با هدف ارتباط و ارسال اطلاعات از سامانه دانشجویی دانشگاه (بوستان) به وب‌اپ ابزار های بوستان (NUSTools) ساخته شده.

## امکانات اصلی ❇️

### دانلود جداول بصورت اکسل 📩
میتونید جداول گروه‌های درسی و جدول چاپ انتخاب واحد رو بصورت فایل اکسل دانلود کنین.

### ارسال اطلاعات بصورت مستقیم به NUSTools 📤
میتونید اطلاعات موردنیازتون رو مستقیما برای ابزار های NUSTools بفرستید.

### پرکردن خودکار (Autofill) نظرسنجی استادان ✅
دیگه نیاز نیست زمان زیادی برای فرم‌های نظرسنجی بی‌اثر بذارین تا نمره‌تون رو ببینین. با یک کلیک فرم با نمره مورد نظر شما پر میشه.

### بدون جمع‌آوری اطلاعات شخصی 🔒
این افزونه هیچ گونه اطلاعاتی از کاربر دریافت و ذخیره نمیکند. تمامی اعمال دانلود فایل‌ها و ارسال اطلاعات روی دستگاه کاربر و با استفاده از مرورگر انجام میشود.  
برای اطمینان خاطر شما از امنیت این افزونه، ما کد منبع این افزونه رو بصورت متن‌باز روی گیت‌هاب قرار داده‌ایم.

### و امکانات دیگر که بزودی اضافه میشوند. 👨‍💻
